# Phase 1 – Planning and Setup

**Goal:** Decide what to build and prepare the workspace.

- Define user roles: shopper and admin/seller
- List features and group them into must-have and later
- Choose stack: MongoDB, Express, React (Vite), Node.js
- Create the repository with `Client` and `Server` folders
- Install Node.js, MongoDB and a code editor; set up Git
- Add `.gitignore` (node_modules, `.env`, uploads where needed)

**Outcome:** Empty but organised project, agreed feature list.
