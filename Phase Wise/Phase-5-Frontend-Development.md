# Phase 5 – Frontend Development

**Goal:** A usable interface connected to the API.

- Create the Vite + React app, set up React Router
- Build shared components: Navbar, Footer, ProductCard
- Add Auth and Cart context providers
- Shopper pages: landing, products, product detail, cart, profile, login, register
- Admin pages: dashboard, seller dashboard, all orders, all products, new product
- Axios service layer, toast notifications, responsive styling
- Inline price/stock editing and low-stock indicators for sellers

**Outcome:** Full user journey works in the browser.
