# Phase 6 – Testing and Deployment

**Goal:** Verify behaviour and publish the app.

- Test each flow: auth, search, cart, checkout, order status, admin actions
- Check access control with and without tokens
- Fix bugs found, test on phone and desktop sizes
- Replace default admin credentials and set a strong `JWT_SECRET`
- Move the database to a hosted MongoDB (e.g. Atlas)
- Deploy with Vercel using `vercel.json`; set environment variables in the host dashboard
- Finalise README and documentation

**Outcome:** Live, documented application.
