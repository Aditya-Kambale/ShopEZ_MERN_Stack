# Phase 2 – Database and Backend Core

**Goal:** A running API connected to MongoDB.

- Initialise the Express server and read settings from `.env`
- Write the database connection module
- Define Mongoose models: User, Admin, Product, Cart, Order
- Add the seed script for sample products and an admin account
- Organise code as routes → controllers → models

**Outcome:** Server starts, connects to the database and can be seeded.
