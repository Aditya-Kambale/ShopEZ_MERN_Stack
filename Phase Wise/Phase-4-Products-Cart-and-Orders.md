# Phase 4 – Products, Cart and Orders

**Goal:** Complete the shopping logic on the server.

- Product CRUD with Multer image upload
- Search, category filter and price sorting on the product list
- Cart endpoints: view, add, update quantity, remove
- Order creation from the cart with address and payment method
- Order history for users; all-orders view and status update for admins
- Dashboard statistics endpoint and user list endpoint

**Outcome:** Every feature works through the API and can be tested with a REST client.
